# GWP Starter Skeleton

This is a **template**, not finished content. It's the Governed Workspace Protocol
knowledge bundle with its frontmatter genericized so you can adapt it to your own
workspace.

Before you rely on these files, search-and-replace the placeholder tokens:

- `<your-team-or-role>` — in `authority.owner` and `steward.team`
- `<yyyy-mm-dd>` — in `timestamp` and `review.last_reviewed`

Then review each asset's `confidence` and `alignment.status` so they reflect the real
maturity of your content.

See `GETTING-STARTED.md` at the top of this download for the full walkthrough, and the
project home for the complete worked example:
<https://github.com/DamCoder/governed-workspace-protocol>
