# Processes

This is an [OKF](../index.md) knowledge category for **processes**: repeatable
procedures, playbooks, and runbooks a workspace follows.

Each process is a single markdown file in this directory with
`type: process` frontmatter — see
[`schemas/gwp-metadata-schema.yaml`](../../schemas/gwp-metadata-schema.yaml).

## Available processes

- [Initializing a Workspace](initializing-a-workspace.md) — AI-assisted setup of a new governed workspace from the starter bundle.
- [Conducting a Collaborative Review](conducting-a-review.md) — a step-by-step review runbook (also a worked example of a process).
