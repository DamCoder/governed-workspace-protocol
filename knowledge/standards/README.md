# Standards

This is an [OKF](../index.md) knowledge category for **standards**: reusable
normative guidance (naming conventions, identity governance, data-classification
rules, etc.) that a workspace agrees to follow.

No standards have been authored yet. Each standard should be a single markdown
file in this directory with `type: standard` frontmatter — see
[`schemas/gwp-metadata-schema.yaml`](../../schemas/gwp-metadata-schema.yaml) and
the [Shared Alignment Context](../governance/alignment.md) for the governance fields.
